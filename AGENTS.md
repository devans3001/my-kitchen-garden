# Agent instructions for this repository

Read `HANDOVER.md` before doing anything. It holds the
decisions of record, the build sequence, and the live status
for the My Kitchen Garden build.

Engineering work follows the fullstack-engineering skill in
`.cline/skills/fullstack-engineering/` (SKILL.md plus
EVANS_ADDENDUM.md). The addendum wins wherever the two differ.

Hard rules:

- No application code until Evans confirms the client deposit
  has landed. Prep, docs and planning are always fine.
- Evans is the only approver. Show each stage and wait for his
  word before pushing further work or publishing anything.
- Update the Status section of HANDOVER.md at the end of every
  work session so the next agent resumes exactly where you
  stopped.
- Do not ask Evans questions that HANDOVER.md or the build
  spec already answer.
